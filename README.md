## Deskripsi
Praktikum ini mempelajari penggunaan JavaScript untuk memanipulasi elemen HTML melalui Document Object Model (DOM), menangani event pengguna, mengubah tampilan halaman, menghitung karakter, melakukan validasi form, serta membuat aplikasi interaktif sederhana.

## Tujuan Praktikum
1. Memahami DOM sebagai representasi dokumen HTML yang dapat diakses melalui JavaScript.
2. Menggunakan `id`, `class`, dan selector CSS untuk memilih elemen HTML.
3. Mengubah teks, atribut, kelas CSS, dan gaya elemen menggunakan JavaScript.
4. Menangani event pengguna menggunakan `addEventListener()`.
5. Membuat validasi form dan menampilkan pesan berdasarkan kondisi input.
6. Mengembangkan halaman web interaktif dengan beberapa fungsi yang berjalan dengan benar.

## Langkah Kerja Praktikum

### Latihan 1 — Mengubah Teks dengan DOM
Memilih elemen HTML menggunakan `getElementById()` dan mengubah judul serta paragraf menggunakan `textContent`.

### Latihan 2 — Event Click
Menggunakan `addEventListener()` untuk merespons klik tombol dan menampilkan waktu ketika tombol ditekan.

### Latihan 3 — Mengubah Kelas dan Gaya CSS
Menggunakan `classList.toggle()` untuk mengubah tampilan paragraf, termasuk warna, latar belakang, garis tepi, dan ukuran teks.

### Latihan 4 — Event Input dan Penghitung Karakter
Menggunakan event `input` untuk menghitung jumlah karakter yang dimasukkan pengguna secara langsung.

### Latihan 5 — Validasi Form Pendaftaran
Membuat form yang memeriksa nama, format email, dan usia. Program menampilkan pesan kesalahan apabila input tidak sesuai dan pesan berhasil apabila validasi terpenuhi.

### Latihan 6 — To-do List
Membuat daftar tugas sederhana yang memungkinkan pengguna menambahkan tugas dan menandai tugas yang sudah selesai.

### Mini Project — Form Pendaftaran Workshop
Mengembangkan form pendaftaran workshop dengan fitur:
- Validasi nama dan email.
- Pilihan sesi workshop.
- Penghitung karakter nama.
- Ringkasan sesi yang dipilih.
- Pesan kesalahan dan keberhasilan.
- Tombol reset form.

## Cara Menjalankan Program
1. Unduh atau clone repository ini ke komputer.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam folder yang sesuai.
4. Buka file `index.html` menggunakan browser.
5. Uji setiap fitur dengan melakukan klik tombol, memasukkan teks, dan mengisi form.
6. Periksa hasil program dan pastikan fitur berjalan sesuai fungsinya.
